# V课表课程 JSON 导入提示词

请把我上传的课表图片或课表文字识别成 JSON。只输出 JSON，不要 Markdown 代码围栏，不要解释。

格式必须是：

{
  "schemaVersion": 1,
  "courses": [
    {
      "name": "课程名称",
      "location": "教学地点",
      "day": 1,
      "start": 1,
      "duration": 2,
      "weeks": [1, 2, 3]
    }
  ]
}

规则：星期一到星期日的 day 为 1 到 7；第几节课用 start 表示，连续课节数用 duration 表示；教学周必须展开为数字数组，例如“1-6周”写成 [1,2,3,4,5,6]，“第15周”写成 [15]；“每周”可写成 1 到 30 的数组。不要编造图片中没有的课程，无法确认的字段使用空字符串或跳过该课程。`courses` 必须是数组。
